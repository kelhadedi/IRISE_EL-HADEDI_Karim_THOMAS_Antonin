# Tregrom Meteo ✧ Expérience de Données Poétiques

Une installation numérique interactive transformant des données météorologiques historiques en une expérience visuelle et poétique immersive.

## 🌊 Le Projet
Ce projet utilise Three.js pour simuler un environnement marin dont les propriétés (couleur, agitation, atmosphère) sont directement pilotées par un dataset JSON de relevés réels de la plage de Trégrom.

### Fonctionnalités :
- **Visualisation Chromatique** : L'océan change de couleur selon la température (interpolation linéaire).
- **Simulation Physique** : L'agitation des vagues est corrélée à la vitesse du vent.
- **Poésie Contextuelle** : Un bouton central permet d'afficher des œuvres de grands auteurs (Paul Verlaine, Arthur Rimbaud, Cécile Sauvage) adaptées à la météo actuelle.

## 🛠 Technologies
- **Moteur 3D** : Three.js (WebGL)
- **Shader** : Water.js
- **Data** : JSON dynamique
- **Design** : Minimalisme inspiré par le projet *Skyhues*
